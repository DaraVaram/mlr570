The idea

Reading about a matrix is not the same as moving one.

These notes started life as LaTeX — good LaTeX, but static. A determinant was a number in a box, an eigenvector was an arrow in a PNG. This site keeps every definition, proof and worked example exactly as it was, and then makes the pictures live.

Drag the actual objects

Grab the columns of a matrix and watch the determinant, the rank and the eigenvectors respond in real time. The intuition arrives before the algebra does.

Break things on purpose

Push the learning rate until gradient descent explodes. Collapse a matrix until it stops being invertible. The failure modes are where the understanding is.

Verified, line by line

Every worked example on this site has been recomputed and checked. Where the original notes had a slip, it is fixed and recorded openly in the errata.

How to use this

Suggestions, not rules.

If you are taking the course

Read the section, then spend two minutes in the playground beneath it before moving on. Try to predict what will happen before you drag anything — being wrong is the fastest way to learn.

The Python snippets are runnable as-is with NumPy. Type them out; do not copy them.

If you are here to revise

Use the sidebar to jump straight to a topic. Every definition, property list and worked example from the original notes is preserved, so nothing you revised from before has moved.

Dark mode is in the top-right, and the site works on a phone — the figures are touch-friendly.
